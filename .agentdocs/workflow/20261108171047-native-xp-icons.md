# XP 原始图标统一重构

## 背景与目标

- 对应会话-39起，用户认为界面拟真度不足，要求所有图标重构并直接使用真实XP系统图标。
- 当前分支为`main`，与上一轮一致，起点`d43bf4b`，工作区干净。
- 替换手绘SVG与现代线框图标，统一桌面、开始菜单、窗口、工具栏、托盘和业务操作。

## 约束与原则

- 系统图标优先采用XP原始资源的16、32、48像素帧，不用生成图片冒充原版。
- Office与QQ单独核对年代与来源；系统资源和第三方软件资源分别记载。
- 图片随生产包提供，运行时不依赖外部图标网站，继续兼容Pages仓库子目录。
- 不改变模拟、游戏存档、资源消耗或原有按钮功能。
- 同一任务的素材、组件、样式、文档和验收合并在本文记录。

## 关键风险

- ICO包含多个尺寸与色深，应保留原生像素与透明度，避免缩放造成模糊。
- 原组件由SVG变成图片后，现有CSS中的`svg`选择器可能失效。
- 替换图标不得影响按钮的可访问名称、命中区域、事件或数据操作。
- 运行在仓库子目录时，图片路径必须由构建工具解析。

## 代码变更与验证

### 实现

- `src/assets/xp-icons/`：56类位图、132个图像帧，来源、原始资源编号、尺寸和SHA-256登记在`manifest.json`。
- `src/config/icons.ts`：资源清单衍生图标类型，统一常用显示尺寸。
- `src/ui/LegacyIcon.tsx`：删除手绘SVG，用本地PNG与原生帧选择器渲染；快捷方式箭头为独立原始图层。窗口关闭、最大化、还原、菜单三角和排序标记改为经典控件字形。
- `src/config/desktop.ts`、`Desktop.tsx`：学生、座位、作业使用独立原始图标；我的文档、最近文档、用户图像、运行、显示属性、注销、快速显示桌面与托盘图标各自映射；回收站在桌面、窗口、任务栏同步切换空/满。
- `ClassicFrame.tsx`、`FileExplorer.tsx`、`LearningApps.tsx`、`StudentApps.tsx`、`SupportApps.tsx`、`Settings.tsx`、`DebugPanel.tsx`、`shared.tsx`：替换所有现代线框图标；联系人头像改用旧QQ默认图像，统计曲线继续使用数据SVG。
- `legacy.css`：移除矢量图标的额外投影，修正PNG和快捷方式布局，统一经典窗口按钮与小字形，适配原来只匹配`svg`的样式。
- `scripts/check-icons.mjs`：检查PNG签名、尺寸、SHA-256、来源与清单完整性，生产构建自动执行。
- `package.json`、`package-lock.json`：删除`lucide-react`，新增`check:icons`。
- `vite.config.ts`：图标输出为带内容标识的资源文件，通过构建工具生成相对路径。
- `index.html`：浏览器图标使用原始XP“我的电脑”。
- `AGENTS.md`、`README.md`、素材说明和文档索引：记录统一图标入口、资源检查方式、来源和新的实机图。

### 浏览器发现并修正

- 约778像素宽的桌面级联打开多个窗口时，原实现会把QQ右侧窗口按钮推到屏幕外。
- 新窗口初始位置现在按其宽度和视口约束，保留右侧4像素边距；原有拖动与最大化行为保持。
- 实测新QQ窗口右边界774，视口778，关闭、最大化、还原按钮均可达。

### 素材取舍

- 系统ICO直接读取已有16/24/32/48像素帧，PNG转换不重新绘画或生成图形。
- Windows标志和用户图片保持原比例。旧QQ具有16/24/32/48像素程序图标，联系人图像为原始16像素。
- Word资料提供原始48像素帧；Excel资料提供原始16像素帧。小尺寸Word按比例缩小，桌面Excel保留像素放大；不将其描述为Office完整多尺寸原件。
- 362份临时原始候选资源只保存在忽略的`.local/`中，发布仅包含筛选后的132个PNG帧和清单。未选用的下载失败候选不进入构建。
- 完整来源和权利归属见`docs/界面参考与素材.md`，不把档案站的代码许可解释成对原产品图形的所有权。

## 测试用例与结果

### TC-ICON-001 原始资源完整性

- 方法：`npm run check:icons`及最终生产构建。
- 结果：56类、132帧的PNG签名、宽高、SHA-256与来源均有效；TypeScript与Vite构建通过。
- 代码检索：没有`lucide-react`引用，唯一界面SVG为`MiniTrend`成绩曲线。
- 状态：通过。

### TC-ICON-002 原生尺寸与加载

- 方法：浏览器查看桌面、开始菜单、Excel与QQ，读取已渲染图片的宽度、原始尺寸和加载状态。
- 结果：桌面系统图标32像素，可见标题栏图标16像素；Excel界面86个图标无缺图，QQ显示50个原始头像且无缺图。
- 状态：通过。

### TC-ICON-003 功能回归

- 方法：Excel最大化、还原，数据菜单筛选临界生再显示全部，工具栏保存后刷新。
- 结果：最大化样式生效、还原正常，50人筛出10人后恢复50人；保存提示成功；旧存档仍为D1、2011/2/28、平均419.4分。
- 状态：通过；测试不推进教学日。

### TC-ICON-004 回收站空满与还原

- 方法：删除“班级观察.txt”快捷方式，打开回收站，再还原所有快捷方式。
- 结果：桌面、窗口标题栏、任务栏均显示`recycle-full`；还原后快捷方式恢复，回收站图标回到空状态。
- 状态：通过，最终已还原测试快捷方式。

### TC-ICON-005 模拟与存档

- 结果：2个测试文件、27/27通过，9.70秒。
