## 关键风险

- Pages 运行在仓库子目录，绝对根路径会导致脚本、CSS 或壁纸404，需检查真实构建产物。
- GitHub Actions 与本地环境不同，需要确认远程安装、测试、构建与部署均成功。
- 在线域名与本地端口的浏览器存储隔离，进度应通过文件导出/导入迁移。
