# 开局文理科选择与六科学科切换

## 背景与目标

- 对应会话-62起，进入新游戏前提供文科班、理科班选择。
- 分支为`main`，与上一轮相同，起点`e827887`，开始时工作区干净。
- 文科使用语数外、政史地；理科使用语数外、物化生。任教仍限语文、数学、英语之一。

## 约束与决策

- 科类属于整局设置，开局后不在原班级中途切换，避免已有知识和成绩失配。
- 教学、学生自主学习、考试、成绩表、导出、报告、调试都使用本局六科。
- 保持虚构750分制；文理各综合三科每科100分，语数外各150分。
- 旧版无科类字段的存档按理科兼容，校验原始摘要后补齐字段，不重建学生或随机状态。
- 修改前保留旧版理科D6基准：种子“旧版科类兼容”、均衡策略5日，关键状态摘要1536512182，随机状态3126901920。
