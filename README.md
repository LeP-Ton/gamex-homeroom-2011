# GameX《高三班主任模拟器：2011》

一个可在现代桌面浏览器运行的单机教学策略游戏。管理 50 位不同的学生，从高考前 100 个教学日开始，通过教学、作业、座位、观察和沟通间接影响他们的成长。

成绩来自知识掌握与考试模型。没有直接加分按钮，不需要服务器、账号、联网模型或第三方 API。首次安装依赖后，游戏运行时不请求外部资源。

本版采用 Windows XP（桌面系统）、Office 2003（办公软件）、QQ 2011与传统校园教务内网的界面结构。游戏内从2011年2月28日开始，桌面、文件名、学年、成绩表、沟通记录与日历统一呈现2011届高三背景。

界面实机：[开局文理科选择](docs/2011-开局文理科选择.png)、[文科成绩表](docs/2011-文科成绩表.png)、[当前桌面与消息气泡](docs/2011-图标与消息修复.png)。历史界面与操作图见`docs/`及对应变更记录。

## 快速开始

环境：Node.js 22.12+（建议 24 LTS）、npm。

```powershell
npm install
npm run dev
```

打开终端显示的本地地址，通常为 `http://127.0.0.1:5173`。Windows 也可以双击根目录的 `启动游戏.cmd` 自动打开浏览器。第一次进入可以选择文科班或理科班，并设置姓名、语数外任教学科、班名、难度、种子和本科参考线。已有自动存档时直接恢复原科类；旧存档按理科兼容。

```powershell
npm test
npm run build
npm run preview
```

`dist/` 是生产静态资源，可由任意静态 HTTP 服务托管；请通过 HTTP 地址运行，直接双击 `index.html` 不支持模块与 IndexedDB 的完整行为。不同端口、不同浏览器属于不同存储空间，可通过导出/导入存档转移。

## 已实现的主要内容

- 确定性班级生成：开局文理科选择，按科类生成50人、六科知识树、相关能力与习惯、心理、目标、家庭、人际关系。
- 百日回合：自主学习、其他任课教师、教学效果、作业、遗忘、疲劳、关系、生态与条件事件。
- XP式桌面：原始XP系统位图、蓝色Luna标题栏、绿色“开始”按钮、双列开始菜单、快速启动、任务栏、系统托盘、经典草地壁纸、多窗口与右键菜单。
- 桌面操作：资源管理器文件入口、最近文档、快捷方式回收站与还原、“运行”命令、注销返回欢迎界面、主题/桌面/外观设置。
- Office式软件：Excel成绩表具有字母列头、行号、公式栏、固定工作表标签、图表工作表和真实排序筛选；Word教学与报告采用菜单、工具栏、标尺及纸张模板。
- QQ式沟通：班级通讯录、联系人检索、消息记录、沟通方案发送、反馈、资源消耗和冷却；教务平台、学生系统、座位与作业共用真实班级数据。
- 统一图标：56类年代位图、136个原始图像帧，包含快捷方式箭头、空/满回收站、托盘与旧版QQ头像；DOC/XLS使用成套16/32/48像素文件图标，并通过`srcset`适配高DPI。来源见素材说明。
- 托盘消息：气泡指向实际入口并保持在任务栏上方，支持关闭、外部点击、Escape、长消息滚动和窄屏避让；QQ手动消息与自动提示共用显示区域。
- 11 个应用：学生档案、座位管理、成绩分析、作业批改、考试管理、教学计划、学生谈话、家校沟通、班级观察、教学日历、高考报告；另有综合工作台。
- 真实操作：拖拽/点击换座位、分层/指定作业、典型错误诊断、课程安排、沟通冷却、事务选择。
- 考试：摸底、可选测验、第 25/50/75 天统一考、第 100 天高考；六科试卷覆盖与有界临场波动。
- 分析：排序、科目/范围/姓名筛选、考试对比、进步排序、偏科/临界生筛选、个人/全班趋势与不确定区间。
- 存档：IndexedDB 自动档、三个手动槽、文件导入导出、校验与版本检查、读档确定性续算。
- 结算：上线人数/率、均分、分科、高分、个人与全班进步、本地历史排名、同种子重开、成绩 CSV、管理记录导出。
- 调试：独立副本、快进高考、真实属性、每日预算与教学收益、考试评分明细、多种子模拟与导出。

## 规则说明

采用虚构750分制：语文、数学、英语各150；理科班的物理、化学、生物各100，文科班的政治、历史、地理各100。科类在新建班级时选择，学习、试卷、成绩表、报告和导出同步切换；任教目前仅支持语文、数学、英语之一。参考线可设为300～650，默认450，仅用于游戏，不代表任何省份真实政策。

教师每日时间/精力：普通 180/100、挑战 150/90、困难 120/80。难度调整初始班级、家庭与资源，不偷偷降低学习收益。学生每天共享 240 分钟学习预算；额外作业和教学会挤占其他学科或恢复时间。

游戏日历从虚构的 2011 年 2 月 28 日到 6 月 7 日，每次推进均按一个教学日处理，不单独模拟周末。统一考试在结束对应日后自动结算。

```powershell
npm run balance -- --seeds=3 --out=.local/balance.json
npm run balance -- --seeds=8 --difficulty=hard --out=.local/hard.json
```

## 数据与扩展

`src/config/game.ts` 定义学科、知识点树、任教选项、考试、行动、难度、事件和姓名。`src/sim/questions.ts` 提供与知识点一致的代表题模板。核心按学科配置遍历，可增加其他任教学科或调整虚构考试方案；修改旧存档结构需要明确迁移并提升版本，不能直接让旧数据静默兼容。

界面仅使用可观察成绩、作答、反馈与教师推测。文件存档必须包含真实状态以供续算，不是加密或防作弊格式。本地排行榜也不提供防篡改竞技认证。
