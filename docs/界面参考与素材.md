# 2011年校园电脑界面

## 本版界面方案

采用Windows XP Luna蓝色桌面、Office 2003、QQ 2011与传统教务内网的组合。Windows、Office与QQ在本游戏中提供界面和操作模拟，业务数据连接本地班级、作业、考试与沟通规则。

| 游戏应用 | 软件界面 |
| --- | --- |
| 教务首页 | Internet Explorer式地址栏、工具栏与2010—2011学年校园内网 |
| 学生、座位、作业、日历 | Windows窗体式教务管理系统、分组框、数据表与经典表单 |
| 成绩分析 | Excel 2003菜单、字母列头、行号、公式栏、只读成绩单与工作表标签 |
| 教学、考试安排、报告 | Word 2003菜单、工具栏、标尺、页面纸张与教务模板 |
| 师生与家校沟通 | QQ 2011式联系人、消息记录、发送方案与反馈 |
| 班级观察 | 记事本式只读记录、来源筛选与文本导出 |
| 我的电脑 | XP资源管理器式文件入口、目录与最近文档 |

桌面还提供快捷方式选择与右键、按名称排列、回收站还原、运行命令、三种窗口配色和两种桌面背景。显示设置不操作用户真实系统。

从ICO提取其已有的位图帧并无损编码为PNG，保留透明度与原始图形，没有生成或手绘替代图。桌面通常使用32像素，标题栏、任务栏和小工具栏通常使用16像素；系统资源存在24/48像素帧时保留用于其他尺寸。快捷方式箭头单独叠加，回收站根据快捷方式回收状态切换空/满图标。

会话-50起，Office文件图标改用同一档案的DOC／XLS成套资源，双方均有16、32、48像素帧。32像素帧的有效图形边界均为`(1,1)～(30,30)`，保证相同显示尺寸下的主体大小一致。浏览器通过`srcset`在高DPI环境选择更密的原始帧，例如32像素显示在125%DPI下使用48像素原图。构建检查要求Office三种尺寸齐全。

上一版本只有Excel 16像素和Word 48像素来源，造成放大方式和留白不同，现已替换。旧来源与取舍保留在对应Git历史和会话-39变更文档中。当前资源取自年代图标档案，不将其描述为从本机Office安装文件提取的完整官方图标组。

Windows标志和原始用户图片按原比例显示。经典窗口按钮、菜单三角和表格排序符使用对应的控件字形；成绩曲线仍使用SVG绘制数据。

Windows与Office图形权利归Microsoft，QQ图形权利归Tencent；档案的代码或目录许可不替代原产品图像的权利归属。逐文件来源保留在清单中。

`npm run check:icons`检查每帧PNG签名、宽高、SHA-256与来源登记，构建自动执行。图像通过Vite生成带内容标识的本地资源路径，支持GitHub Pages的仓库子目录。
