## 平衡工具

```powershell
npm run balance -- --seeds=3 --out=.local/balance.json
```

- `--seeds=1..100`：每档难度的班级种子数。
- `--difficulty=normal|challenge|hard|all`：默认三档全部。
- `--out=路径.json`：JSON 以及同名 CSV 输出；默认 `.local/balance.json`。
- 同一班级分别运行四套规则策略，不接入 UI 和 IndexedDB。

| 策略 | 行为 | 主要取舍 |
| --- | --- | --- |
| 仅常规教学 | 系统课程与学生自主学习 | 保留恢复与其他学科，缺少针对性支持 |
| 均衡教学与恢复 | 轮转讲解/练习/复习、16题适量作业、周期休整、考前疏导、跟进事务 | 全班和总分更均衡，单个临界生投入有限 |
| 高负荷重复训练 | 同一点反复讲解/练习/复习、60题高难作业 | 知识覆盖失衡、挤占其他学科、疲劳 |
| 只关注临界生 | 三名最近考试临界生专项辅导和作业 | 少量学生效率较高，其余学生机会成本 |

观察均分、上线率、分科、进步、疲劳与压力，按种子配对比较。不只比较单科，不把单个种子的输赢解释为全局定论。

## 关键参数

- 学习基础速率：每分钟 `0.00155`，还需乘以个体、状态、生态、知识难度与递减项。
- 基础课程：每科需求 23 分钟，与额外教学共享剩余预算，需求过高则同比缩放。
- 作业：每完成一题 2 分钟；超过约 45 分钟的负担额外增加疲劳与压力。
- 熟练度：增长有上限，削弱重复训练增量；未练习的知识会衰减。
- 状态：每天小幅积累和恢复；家庭支持改善恢复，高压与过量任务增加负担。
- 谈话：同生三天、家校五天；集体疏导三天，所有行动有教师成本。

## 验证记录

生产构建通过，浏览器中已验证真实换座、教学扣费、50份作业、诊断、谈话、事务处理、成绩筛选排序、日结刷新恢复、手动槽和存档文件往返，以及副本快进高考。

本次批量样本为3个种子×3档难度×4套策略，共36局、3600教学日，耗时61.4秒。结果见 [平衡样本 JSON](平衡样本.json) 与 [平衡样本 CSV](平衡样本.csv)。均衡策略的平均均分相对常规策略提高约10.5～12.7分；过量重复训练的均分和其他学科表现更差。此样本不能证明所有种子或所有策略的全局结论。

初版模拟和平衡记录见 `.agentdocs/workflow/20261108150030-build-playable-game.md`；2011界面、27项回归和Office/QQ操作记录见 `.agentdocs/workflow/20261108160437-2011-desktop-redesign.md`。尚未进行大规模种子穷举与各浏览器逐一兼容测试。后续平衡修改应同时更新受影响的用例和配对种子统计，避免为让策略赢而直接修改成绩。
